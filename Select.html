• span = petit morceau de texte
  • p = paragraphe
  • label = texte lié à un champ
  • section = partie de page
  1. <ol> = liste ordonnée, avec numéros
  2. <li> = toujours les éléments de la liste
  3. <ul> = liste non ordonnée, avec des puces
  4. <dl> = liste de définitions, avec des termes et des descriptions
  5. <dt> = terme dans une liste de définitions
  6. <dd> = description dans une liste de définitions
