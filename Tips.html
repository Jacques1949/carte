La balise html lang="fr" indique que la langue principale de la page HTML est le français. Concrètement, ça aide : les navigateurs à choisir les bonnes règles typographiques ou de traduction ; les lecteurs d’écran à prononcer le texte avec une voix française ; les moteurs de recherche à comprendre la langue de la page ; les correcteurs orthographiques à utiliser le français.

La balise meta charset="UTF-8"indique que le document HTML utilise l’encodage de caractères UTF-8, qui est un standard pour représenter les caractères de la plupart des langues du monde, y compris les caractères accentués utilisés en français. Cela permet d’afficher correctement les caractères spéciaux et les accents dans le navigateur.

La balise meta viewport est utilisée pour contrôler la mise en page sur les appareils mobiles. Elle indique au navigateur comment ajuster la taille et l’échelle de la page pour s’adapter à l’écran de l’appareil, assurant ainsi une expérience utilisateur optimale sur les smartphones et les tablettes.
